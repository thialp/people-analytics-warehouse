## 2. Dashboard #2: Compensation Walk

Four kinds of change. Part A must be done, or some selections silently show nothing. Part B uses the new columns. Part C is the extract and publish. Part D, the career moves panel, is its own session.

### A. Required: new Custom SQL and two renamed values

**A1. Walk Custom SQL.** Data Source tab of `ArcadiaHR` > the Custom SQL table > **Edit Custom SQL Query** > select all, paste the whole of `tableau/custom_sql_compensation_walk.sql` > OK. (The extract is refreshed in part C; a Custom SQL edit on an extract source asks to refresh, so leave that for C.)

**A2. Office moves Custom SQL.** The same on `Office Moves`, with `tableau/custom_sql_office_moves.sql`. It adds the field `open_headcount`.

**A3. `Leader` is now `Sub-function`.** The data says `Sub-function` in `view_name`. Anything that tests the text `"Leader"` now matches nothing, and the Leader button would show an empty page:

1. Parameter `p_View` > Edit > in the list, change the value `Leader` to `Sub-function` (Display As `Sub-function`).
2. Data pane, `view_name` > right-click > **Aliases...** > if `Leader` has an alias, **Clear Aliases** (the name is now right in the data).
3. Calcs with a `CASE [p_View]`: `Panel Title` (`WHEN "Sub-function" THEN "a sub-function"`), and `Selected Group` if the fallback pickers were built (`WHEN "Sub-function" THEN [p_GroupSubfunction]`, after renaming the parameter `p_GroupLeader` to `p_GroupSubfunction`).
4. Find any other: in the Data pane search box type `Leader`; also open each title that mentions the view.
5. Departments with no sub-function keep their function's name as the group (the view still covers the whole company). Optional tooltip line on the View rail: "no sub-function: shown at function level".

**A4. `Relocation Adjustments` is now `Same-Country Transfer Adjustments`.**

1. `TD Key`: change `WHEN "Relocation Adjustments" THEN "Relocation"` to `WHEN "Same-Country Transfer Adjustments" THEN "Same-country move"` (it reads alongside "Cross-border move").
2. `TD Why`: change `WHEN "Relocation" THEN ...` to `WHEN "Same-country move" THEN "Pay reset to a new office in the same country: " + [TD People Label] + "."`
3. `step` > **Aliases...**: the alias on the old value is gone with the value; give `Same-Country Transfer Adjustments` the alias `Same-country move` (the Expand waterfall axis).
4. Search the Data pane for `Relocation` and fix any other calc or tooltip.

**A5. Custom Range.** The grid no longer has Custom Range pairs. Calcs that name it still work (the branch is never reached); delete the branch in `Pair Name` only if you want the calc clean.

### B. New columns (small additions)

**B1. Data dates from the data.** Both Custom SQL sources now carry `report_start_date` and `report_as_of_date`.

```
// Data As Of   (walk source)
{ MAX([report_as_of_date]) }

// Data Start   (walk source)
{ MIN([report_start_date]) }

// Data Note   ("Data covers Jun 30, 2022 to Jun 30, 2026")
"Data covers " + LEFT(DATENAME('month', [Data Start]), 3) + " " + STR(DAY([Data Start])) + ", " + STR(YEAR([Data Start]))
+ " to " + LEFT(DATENAME('month', [Data As Of]), 3) + " " + STR(DAY([Data As Of])) + ", " + STR(YEAR([Data As Of]))
```
- Page subtitle and the Period popover note: replace the static "Data through Jun 30, 2026" with `<ATTR(Data Note)>` (Insert > the field, in the title or text editor).
- `Default To` = `[Data As Of]`, `Default From` = `DATE(DATEADD('year', -1, [Data As Of]))` (`DATEADD` returns a date and time; `DATE()` keeps the Date type the parameter needs). Then the parameters `p_To` and `p_From` > Edit > **Value when workbook opens** = `Default To` / `Default From`. Reset and the opening state now follow the data instead of a typed date.

**B2. Share of headcount in the map title.** In `Office Moves`:

```
// Moves Open HC   (the group's opening headcount; NULL for a group that did not exist at the From date)
MIN(IF [Move In Scope] THEN [open_headcount] END)

// Moves Share Text   (one decimal with integer math, like the other text calcs)
IF ISNULL([Moves Open HC]) OR [Moves Open HC] = 0 THEN ""
ELSE " (" + STR(DIV(INT(ROUND(1000 * [Movers] / [Moves Open HC], 0)), 10)) + "."
     + STR(INT(ROUND(1000 * [Movers] / [Moves Open HC], 0)) % 10) + "% of headcount)" END
```
In `Moves Title`, change the last branch to `STR([Movers]) + " people changed office" + [Moves Share Text] + "; " + STR(ROUND(100 * [Movers Within] / [Movers], 0)) + "% stayed inside one country"`. FY26 Company: **725 people changed office (2.5% of headcount); 83% stayed inside one country**.

**B3. Growth by region follows View and Group.** Today the card reads the walk's Country rows, so it always shows the company. The new region walk gives each group its own regions.

1. **Data > New Data Source** > Microsoft SQL Server, the same connection as `ArcadiaHR` (localhost, database `ArcadiaHR`, the `.tdc` trust setting as before) > **New Custom SQL** > paste `tableau/custom_sql_region_walk.sql` > OK. Rename the source `Region Walk`. Connection **Extract** (part C).
2. Calcs in `Region Walk` (parameters are shared by every source, so no blending is needed):
```
// RW In Pair
[from_month_end] = [p_From] AND [to_month_end] = [p_To]
AND [view_name] = [p_View] AND [group_name] = [p_Group]

// Open HC        SUM(IF [RW In Pair] THEN [opening_headcount] END)
// Close HC       SUM(IF [RW In Pair] THEN [closing_headcount] END)
// Departures     SUM(IF [RW In Pair] THEN [exits] + [transfers_out] + [region_moves_out] END)
// Growth %       IF [Open HC] > 0 THEN [Close HC] / [Open HC] - 1 END
// Net Change     [Close HC] - [Open HC]
// Tot Open       { FIXED : SUM(IF [RW In Pair] THEN [opening_headcount] END) }
// Tot Close      { FIXED : SUM(IF [RW In Pair] THEN [closing_headcount] END) }
```
   Copy `Share of Growth`, `Tot Open Text`, `Tot Close Text`, `Tot Growth Text` and `Region Subtitle` from the walk source (right-click > Copy, then right-click in `Region Walk` > Paste); they keep working because the names match. In `Region Subtitle`, replace "Arcadia overall" with `IF [p_View] = "Company" THEN "Arcadia overall" ELSE [p_Group] END`.
3. Sheet `Region Headcount`: right-click the tab > **Duplicate**. In the copy, on each shelf, swap the walk fields for the `Region Walk` ones (`group_parent` → `region`, `Open HC`, `Close HC`, `Growth %` from `Region Walk`). Add `RW In Pair` to Filters = True. Then swap the copy into the dashboard in place of the old sheet (select the old one on the dashboard, its menu > **Swap Sheets**) and delete the old sheet.
4. A group with no one in a region at both ends (a region the group does not reach) has no row, so it simply drops out of the card.
5. Optional: `Departures` in the tooltip ("Left this region: N").
