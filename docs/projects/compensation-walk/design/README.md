# Dashboard #2 Summary page: design sketch and build sheet

Design for the Summary page of the Compensation Walk dashboard. Same 1400 x 850 canvas as Dashboard #1, with a vertical filter rail on the left. All numbers are the FY26 company walk (loaded cost, constant currency); the company is fictional and the data was generated by Claude Code.

| File | What it is |
|---|---|
| `Compensation_Summary_PerFTE_OfficeMoves.svg` / `.png` | Default state: lens Per FTE, bottom panel Office moves |
| `Compensation_Summary_Total_CareerMoves.svg` / `.png` | Other state: lens Total, bottom panel Career moves |
| `Compensation_Colors_and_Buttons.svg` / `.png` | Colors with roles, and the On/Off look of every toggle |
| `build_sketch_svg.py`, `sketch_data.json` | Regenerates the SVGs (`python build_sketch_svg.py sketch_data.json .`) |

SVG layers are named the way the Figma UI kit names them: **Background (export)** (cards, rail, control outlines) and **Tableau objects** (every sheet, text and control that floats in Tableau). To use in Figma: open the file, drag an SVG onto the canvas (text stays editable), and place it on the Dashboards page.

## Color and state rules

- Teal `#00938D` increase, coral `#E4572E` decrease, warm gray `#8C8A84` Opening and Closing, violet `#5B4FB3` moves within one country, amber `#D98E04` one highlight at most (callouts, Director bracket).
- Toggle On is filled (white on the navy rail, navy on the page), Off is an outline. Capsule radius 16 in Tableau, cards 10, rail controls 0.
- Each state is its own custom-shape PNG, as in Dashboard #1.

## Data

| Part | Source |
|---|---|
| KPI cards, waterfall, top drivers | Custom SQL `tableau/custom_sql_compensation_walk.sql`; every sheet filters to one view and one date pair (averages must never be summed across groups) |
| Office moves panel | Custom SQL `tableau/custom_sql_office_moves.sql` (same date pair, views and group names as the walk, so the map follows the rail filters; see `../office_moves.md`) |
| Career moves panel | `mart_headcount_fte_walk`: Internal Moves In, reason Promotion or Demotion, by grade |

Checks against the warehouse: FY26 Company opening 28,436 people and $3,000.1M, closing 30,015 and $3,195.5M; per FTE $107,553.68 to $108,706.49 (+$1,152.81); 345 people changed office (227 within one country, 118 across a border); 2,138 promotions and 114 demotions, 16 into Director or Senior Director.
