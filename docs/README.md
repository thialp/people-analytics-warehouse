# Documentation

Docs are grouped by **project** (a business question answered on the shared warehouse), not by dashboard. A project can have several dashboards, and they all read from the same warehouse tables.

| Folder | What is in it |
|---|---|
| [`company/`](company/README.md) | **Start here.** Who Arcadia Systems is (a fictional company generated by Claude Code), what it does, where it is, the leadership [org chart](company/org_chart.md) and the [organization and pay model](company/organization_and_pay_model.md) |
| [`warehouse/`](warehouse/data_dictionary.md) | Data dictionary for the raw tables and marts, shared by every project |
| [`setup/`](setup/sql_server_local_setup.md) | Run it yourself: [SQL Server in Docker](setup/sql_server_local_setup.md), [Docker Compose](setup/docker_compose_guide.md), [connecting Tableau Public](setup/tableau_public_guide.md) |
| [`brand/`](brand/README.md) | Arcadia logo, color palettes and style rules used by every dashboard |
